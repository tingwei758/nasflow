# flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single Python container that polls qBittorrent for completed torrents, identifies them via TMDB, and hardlinks them into a staging tree named for Plex — stopping for human confirmation whenever it is unsure.

**Architecture:** A pure-function core (parse → scan → match → path) wrapped by two I/O shells: a background poller that drives the pipeline, and a FastAPI app serving the board. All state lives in one SQLite file. Every module that touches the filesystem is given its roots by config so tests run against `tmp_path`.

**Tech Stack:** Python 3.12, FastAPI + uvicorn, httpx, guessit, SQLite (stdlib `sqlite3`), pytest, Docker.

**Spec:** `docs/superpowers/specs/2026-10-18-flow-design.md`

## Global Constraints

- **Never write outside the staging root.** Source files under `/volume1/docker/qb/downloads` are read-only to flow. flow needs no access to `/volume1/Media` at all.
- **Hardlinks only** (`os.link`). Never `shutil.copy`, `shutil.move`, or `cp`. A hardlink into staging is the only file-creating operation in the program.
- **No path, directory name, filename template, or extension list may be hardcoded.** Every one is a `Config` field with the spec's value as its default. A test in Task 1 asserts that non-default values are honoured end to end. Code may not contain the literals `/volume1`, `Movies`, `TV Shows`, `Season `, `/downloads`, or any media extension outside `config.py`'s defaults.
- **Default staging root:** `/volume1/docker/qb/staging` (host), containing `Movies/` and `TV Shows/`.
- **Default naming:** `Movies/标题 (YYYY)/标题 (YYYY).ext` and `TV Shows/标题 (YYYY)/Season N/标题 - SxxEyy.ext`. `Season 1` not `Season 01`. Specials go in `Season 0`. Simplified Chinese title when TMDB has one, English otherwise.
- **Classification comes from the files inside, never the torrent name.**
- **The trigger is the qBittorrent WebUI API, never a directory watcher.** The filesystem cannot distinguish complete from incomplete.
- **No duplicate checking.** flow never scans the Plex library.
- **No authentication; LAN-bind only.** The container port must not be published beyond the local network.
- **Never log the TMDB API key.**
- **Prune empty directories only, never files.**
- **Thresholds are configuration, not constants.**
- Python 3.12. `pytest` for tests. Format with `ruff`.

## Review Focus

Input classes the spec implies but no task's happy path exercises. Each has a test added to the owning task.

1. **`Exx` with no `Sxx`** — `Eight.Hours.Dont.Make.a.Day.1972.E01-E05...` is a real item. A strict `SxxExx` regex classifies it as a movie and links five episodes over each other. Expected: recognized as episodes, or stopped — never silently collapsed. (Task 3)
2. **A movie whose name contains a series title** — `El.Camino.a.Breaking.Bad.Movie.2019` must resolve to the film, not the show. (Task 4)
3. **Destination already exists** — re-processing a torrent, or a re-download of the same episode. `os.link` raises `FileExistsError`. Expected: identical existing link is a no-op success; a different file stops the item. Never silently overwrite. (Task 6)
4. **Single-file torrents** — qBittorrent's `content_path` is the file itself, not a directory (`[黑亚当]Black.Adam.2022...mkv` is a real example). Scanning must handle both shapes. (Task 3)
5. **TMDB unreachable, rate-limited, or returning zero results** — expected: the item stops in `needs_you` with the reason recorded, and is retried on a later pass. A network blip must never be recorded as "not media". (Task 4)
